# V5-DEX

Design documents and the simulator for a chain-agnostic exchange built around V5 pools: liquidity positions that season in an epoch hall and are paid from real fees.

- `docs/` holds the spec, the handoff brief, the external review and the list of rulings needed.
- `sim/` holds the simulator. See `sim/README.md`.
- `src/` and `test/` hold the first contracts and their tests. See `src/README.md`. Not audited.
